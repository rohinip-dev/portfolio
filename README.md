# 🌸 Rohini Pandit | Portfolio

A responsive, animated personal portfolio for a UI/UX designer and web developer, built with plain HTML, CSS, and JavaScript. No frameworks and no build step.

**🔗 Live site:** https://rohinip-dev.github.io/portfolio/

---

## ✨ About

Hi, I'm **Rohini Pandit**, a BCA and MCA graduate, aspiring UI/UX designer, and web developer who loves creativity, technology, and beautiful digital experiences. This portfolio brings together my projects, skills, journey, design work, and YouTube channel in one place.

## 🎯 Features

- **Loading screen** with a progress bar, plus a scroll progress bar and back-to-top button
- **Typing animation** and shimmering gradient text in the hero section
- **Glass-style navbar** with smooth scrolling and a mobile hamburger menu
- **Dark and light theme** toggle that remembers the visitor's choice
- **4 colour moods** (Dreamy, Rose, Mint, Cream) via a colour picker
- **Project cards** with 3D tilt effect and a detailed pop-up viewer
- **Animated stats counters** and a "Currently" card
- **Skills section** with pills that pop in one by one
- **Journey timeline** covering education and internship
- **Design gallery** with an image viewer (arrow keys and Esc supported)
- **Embedded YouTube video** that loads only when clicked, to keep the site fast
- **Working contact form** (via Formspree) and a copy-email button
- **Background music** toggle (off by default)
- **Sparkle cursor trail** and a hidden easter egg
- **Resume download** button
- **Accessible and responsive:** keyboard navigation, skip link, screen-reader labels, reduced-motion support, and mobile-friendly layout

## 🛠️ Built with

- HTML5
- CSS3 (custom properties, Grid, Flexbox, animations)
- JavaScript (vanilla)
- [Google Fonts](https://fonts.google.com/): Inter and Space Grotesk
- [Formspree](https://formspree.io/) for the contact form

## 🚀 Run it locally

1. Download or clone this repository:
   ```bash
   git clone https://github.com/rohinip-dev/portfolio.git
   ```
2. Open the folder in VS Code.
3. Install the **Live Server** extension, then right-click `index.html` and choose **Open with Live Server**.

You can also double-click `index.html` to open it in a browser. Some features, such as copying the email, work best through a local server.

## ✏️ Customise

- **Text and projects:** edit `index.html`, and the `projects` list at the top of the project pop-up section in `script.js`
- **Colours:** change the variables at the top of `style.css` (`--violet`, `--pink`, `--mint`)
- **Contact form:** replace the Formspree form ID in the `<form>` tag in `index.html`
- **YouTube video:** change the `data-id` of the video button in `index.html`
